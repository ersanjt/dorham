# 06 — Why the name is Dorham

## Name

**English / store:** Dorham
**Persian:** دورهم
**Pronunciation:** DOR-ham
**Tagline FA:** دورهم، توی همین شهر
**Tagline EN:** Your people, in this city

## Why this name

| Test | Result |
| --- | --- |
| Meaning | دورهم یعنی جمع شدن با هم. جامعه است، نه قرار عاشقانه. |
| Not dating-coded | Words like یار، عزیزم، مچ، سوآیپ immediately read as Tinder. دورهم does not. |
| Bilingual | Latin spelling is easy for App Store, Turkish friends, and domain. |
| Speakable in TR / EN | Two syllables. No q / gh / kh problem. |
| Emotional fit | Diaspora loneliness is “I have nobody to go out with tonight.” دورهم answers that. |
| Room to grow | Can mean events, friends, later dating, later other cities. |

## What we rejected

- **Peyvand** — serious, corporate, less warm
- **Didar** — only “meeting”, misses weekly gathering
- **Hamrah** — generic companion apps already exist
- **Yar / Azizam-likes** — dating clone branding
- **Istanbul-only names** — we will add Ankara / Izmir later
