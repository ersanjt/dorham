# Contributing

1. Read `AGENTS.md` and `docs/00-north-star.md`.
2. Branch from `main`: `feat/`, `fix/`, `chore/`, `docs/`.
3. Change Zod contracts in `packages/shared` before controllers.
4. Add a Prisma migration for schema changes.
5. Open a PR / MR with the template. CI must pass.

Do not commit `.env`, photos, or dumps.
